Todo API Documentation

A simple API for managing Todo list using CRUD operations

Overview

The Todo API allows you to create, read, update, and delete Todo list. Each Todo item has the following attributes:

  • title (string): The title of the Todo item.
  • description (string, optional): Additional details about the Todo item.
  • created_at (datetime): The timestamp when the Todo was created.
  • isCompleted (boolean): Indicates whether the Todo is completed.

Endpoints

1. Retrieve All Todos

GET : /api/todo/all

Request:
GET /api/todo/all

Response:
[
    {
        "id": 1,
        "title": "Buy groceries",
        "description": "Milk, eggs, and bread",
        "created_at": "2025-01-12T15:30:00Z",
        "isCompleted": false
    }
]

2. Create a New Todo

POST : /api/todo/post

Request:
POST /api/todo/post/
Content-Type: application/json

{
    "title": "Go to the gym",
    "description": "Morning workout session"
}

Response:
{
    "id": 2,
    "title": "Go to the gym",
    "description": "Morning workout session",
    "created_at": "2025-01-12T16:00:00Z",
    "isCompleted": false
}

3. Update a Todo

PUT : /api/todo/update/<id>/

Request:
PUT /api/todo/update/1/
Content-Type: application/json

{
    "title": "Buy groceries",
    "description": "Milk, eggs, bread, and butter",
    "isCompleted": true
}

Response:
{
    "id": 1,
    "title": "Buy groceries",
    "description": "Milk, eggs, bread, and butter",
    "created_at": "2025-01-12T15:30:00Z",
    "isCompleted": true
}

4. Delete a Todo

DELETE : /api/todo/delete/<id>/

Request:
DELETE /api/todo/delete/1/

Response:
{
    "message": "Todo deleted successfully."
}
